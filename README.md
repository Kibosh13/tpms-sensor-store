# ProДатчики

Многостраничный статический прототип интернет-магазина датчиков давления в шинах TPMS: подбор по автомобилю и VIN, масштабируемый каталог, карточки товаров, услуги, доставка, самовывоз и корзина.

## Структура

- `site/` — готовый статический сайт без сборщика и серверных зависимостей.
- `site/catalog.html` — каталог с поиском, фильтрами, сортировкой и пагинацией.
- `site/product.html?id=...` — динамическая карточка товара.
- `site/selection.html` — подбор по автомобилю и VIN.
- `site/services.html`, `site/delivery.html`, `site/contacts.html` — самостоятельные информационные страницы.
- `site/catalog-data.js` — демонстрационный источник товаров, который можно заменить выгрузкой из CMS/1С.
- `main` — исходники проекта.
- `gh-pages` — опубликованная демонстрационная версия.

## Локальный запуск

```bash
cd site
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173/`.

## Ограничения демоверсии

Каталог можно менять после загрузки реального ассортимента. Фильтры марок автомобилей собираются из поля `coverage` товаров, а производители — из поля `brand` доступных позиций. Применимость нужно передать в данных товара или импортировать из каталога поставщика; по одному названию товара она не определяется. Отдельно заполнять список вариантов фильтра не требуется.

В каталоге отображаются активные товары с `stock > 0`. Производитель без доступных товаров в текущей выдаче скрывается из фильтра; уже выбранный вариант остаётся доступным для сброса. Если закончились только датчики, но остались вентили того же производителя, бренд сохраняется в общем каталоге и исчезает при выборе типа «Датчики». При пополнении остатка товары и бренд возвращаются. На главной странице пока используются отдельные демонстрационные карточки.

В статической демоверсии остатки берутся из `site/catalog-data.js` и обновляются при изменении и публикации файла. Синхронизация с реальным складом/1С ещё не подключена. Частота сохраняется как характеристика и внутренний параметр точного подбора; отдельных фильтров частоты и наличия нет.

Демонстрация работает полностью в браузере. Корзина сохраняется в локальном хранилище устройства, но формы не отправляют данные на сервер, онлайн-оплата и фактическое оформление заказа не подключены.

VIN проходит локальную проверку формата и декодируется через официальный API vPIC NHTSA. Декодирование VIN определяет автомобиль, но не заменяет профессиональный каталог применяемости TPMS: неподтверждённые сочетания не получают случайную рекомендацию и отправляются на ручную сверку OE-номера.

Индексация GitHub Pages закрыта через `robots.txt` и метатег `robots`. Перед публикацией боевого сайта эти ограничения нужно удалить.

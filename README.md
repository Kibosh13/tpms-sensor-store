# ProДатчики

Статический прототип интернет-магазина датчиков давления в шинах TPMS: подбор по автомобилю, каталог, услуги, доставка, самовывоз и корзина.

## Структура

- `site/` — готовый статический сайт без сборщика и серверных зависимостей.
- `main` — исходники проекта.
- `gh-pages` — опубликованная демонстрационная версия.

## Локальный запуск

```bash
cd site
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173/`.

## Ограничения демоверсии

Демонстрация работает полностью в браузере. Корзина не сохраняется после перезагрузки, формы не отправляют данные на сервер, онлайн-оплата и фактическое оформление заказа не подключены. Совместимость для неподтверждённых автомобилей требует ручной проверки по VIN.

Индексация GitHub Pages закрыта через `robots.txt` и метатег `robots`. Перед публикацией боевого сайта эти ограничения нужно удалить.
